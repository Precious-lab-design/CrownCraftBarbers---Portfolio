**Crown & Craft Barbers**

A full-stack barber shop booking web application built with **C#, ASP.NET Core MVC, Entity Framework Core, and SQLite**.

The application provides a responsive interface where customers can explore barber services, select a barber, and book appointments. This project demonstrates practical experience in web application development, database integration, input validation, testing, debugging, and deployment.

**Live Demo:** [View Crown & Craft Barbers](https://crowncraftbarbers.onrender.com)

**Project Overview**

Crown & Craft Barbers is a full-stack web application developed to provide a convenient online appointment booking experience for a barber shop.

The application allows customers to select a service, choose a barber, specify an appointment date and time, and submit their booking details. Booking information is stored in a SQLite database using Entity Framework Core.

The project was developed to apply software development concepts in a practical setting, from designing data models and implementing application functionality to testing and deploying a working web application.

**Features**

- **Service and barber selection:** Customers can select their preferred service and barber.
- **Appointment booking:** Customers can choose an appointment date and time and provide their details.
- **Database integration:** Service, barber, and booking information is managed using Entity Framework Core and SQLite.
- **Input validation:** Booking submissions are validated to help prevent invalid data.
- **Appointment conflict checks:** The application checks for conflicting bookings.
- **Calendar event generation:** Appointment details can be used to generate calendar events compatible with Google Calendar and Apple/Outlook calendar workflows.
- **Responsive interface:** HTML, CSS, and JavaScript support the application's user interface.
- **Booking confirmation:** Customers receive an on-screen confirmation after submitting a booking.
- **Public deployment:** The application is hosted on Render.

 **Application Architecture**

The application follows the Model-View-Controller (MVC) architectural pattern, separating data models, request handling, and user interface components.

- **Models:** Represent application data, including services, barbers, and bookings.
- **Views:** Provide the user interface through Razor views.
- **Controllers:** Handle incoming requests and coordinate application operations.
- **Database:** SQLite stores application data, accessed through Entity Framework Core.
- **Frontend assets:** CSS and JavaScript support the presentation and interactive behaviour of the application.
